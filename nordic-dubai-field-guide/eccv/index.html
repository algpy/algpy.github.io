9.08 · 周二 · Workshop / Tutorial 第一天

会议第一天：先把 Malmö 的“近距离高质量”玩明白

第一天优先熟悉会场周边，空档不跨远距离。Hyllie 到市中心只用一站，任何时刻都能及时回到会议。

核对官方会期
会后 1–3 小时 · 17:30–20:30

Malmö Saluhall + Hyllie Arena晚餐

最稳、最不容易迟到的第一天方案：有室内、有热食，晚点回 Hyllie 也容易。

路线Hyllie → Malmö C → Saluhall → Hyllie Arena → 酒店

A优先
01
Malmö C 南侧

Malmö Saluhall

停留45–60 分钟
交通Hyllie 乘 Skånetrafiken 区域列车到 Malmö C，车程约 7 分钟；从车站步行约 8–12 分钟，门到门按 25 分钟算。

它有什么特点：旧工业空间改成的本地餐饮市场，摊位集中、选择跨度大。

你会体验到：看一圈后先买热食，再决定是否坐下；鱼、肉、素食和面包可以分开买，不必迁就同行口味。

02
Hyllie 会场区

Malmö Arena 会场内部

停留20–30 分钟
交通Saluhall 回 Malmö C 后乘车到 Hyllie，最后步行约 5–10 分钟；是否能进入内部以当晚活动和工作人员安排为准。

它有什么特点：大型会展与演出场馆的看台、环形动线和现场氛围，比普通街区建筑更能体现 Hyllie 的会展尺度。

你会体验到：如果当晚有公开活动或允许进入的公共区域，可以在入口和看台附近感受空间；没有活动就只看开放区域，不闯入检票区或后勤区。

吃什么、什么味道

市场分食：鱼汤 / 热菜 / 肉桂卷

瑞典南部口味偏温和，鱼、土豆、黑麦面包和奶油酱比较常见；先看摊位当天菜单。

约 150–300 SEK · 不追固定名店，市场内现场选择最适合会议日；18:45 后若摊位陆续收档，直接在 Malmö C 或 Hyllie 吃。
交通与时间缓冲

返程至少留两班列车余量。不要只看“车程 7 分钟”，还要算站内步行、等车和找摊位的时间。
