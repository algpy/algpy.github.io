05
SPACE & GEOMETRY

空间（Space）不是地图面积，而是你能安全做事、还能选择进退的范围

同一块地，上一秒可能安全，下一秒就可能送命，因为敌人的枪线、控制技能、队友的支援视线和你的保命技能都在变。空间不是“占过就算我的”，而是“现在能不能安全使用”。

先说人话
空间不是“我站过的地”，而是“我敢在这里做事的范围”

一块地如果你一露头就会被秒，虽然地图上能走过去，但它并不真正属于你。好的空间意味着：你能输出、治疗或控制，同时还有掩体、支援和退路。

高台为什么常常值钱？

不是因为“高就是好”，而是它通常提供更多可见目标、更少可被攻击角度、更好的退路和更强的重力/近战隔离。若队伍脱节或对手能轻松接近，高台也可能变成孤岛。

侧面角度（Angle）为什么值钱？

角度让敌人无法用一个掩体同时挡住多条威胁线。多个角度的真正价值，是让敌方的“安全解”减少。

窄口（Choke）为什么危险？

通过窄口时，你的移动选项被压缩，对方容易把多种压力叠在同一区域。过窄口最怕所有人只能从一个门挤进去。真正的解决办法通常不是更用力地冲，而是想办法多出一条路线、一个侧面角度或一个能安全推进的时机。

Blizzard 在 OW2 地图设计说明里明确提到：因为少一名坦克，团队给旧地图增加了更多掩体；而 Suravasa 的重做又重点调整了 sightline、cover、flank route、connecting path 与高台进入方式。地图设计本身就在告诉你：掩体、视线和路线数量就是战斗选择权。

空间质量

一块空间值不值钱，不看面积，看它给了你多少“可做的事”

能产生作用

能打到关键目标、能治疗队友、能控制入口，而不是站得很远“很安全”却什么也做不了。

能少花资源

一步能回掩体、高台让近战英雄接近要绕路，这些都让你用更少治疗和技能维持压力。

能得到支援

队友能看见你、能跟进你的目标、能在你出问题时帮你。孤立的好角度，经常只是高收益高破产风险。

能退出

真正可控的空间必须允许你在局面变差时撤出。没有退出路线的空间，很多时候只是暂时借来的。

为什么“压力会创造空间”？

因为敌人一旦害怕某条枪线、某次跳脸或某个控制，就不敢自由站在那里。空间不是被坦克用身体“推出来”，而是对手因为威胁而放弃某些选择。

06
DEATHOLOGY

不要只问“最后怎么死的”，要往前找：从哪一秒开始，你越来越难活下来

最后一枪只是结算。真正应该复盘的是前 5～15 秒：你什么时候让自己的选择越来越少，直到敌人只要正常执行就能杀你。

先说人话
死亡通常只是账单最后寄到

屏幕变黑那一秒往往不是最早的错误。真正的问题可能发生在 10 秒前：你多贪一枪、没跟队友退、提前交了保命技能，后面只是一步步把欠下的风险还回来。

信息漏读没看到威胁/队友状态
错误判断以为自己仍有行动权
错误位置暴露时间/退路变差
不必要压力被迫掉血
被迫交技能资源不是主动投资
位置失效同一坐标突然不安全
敌方出手机会对方看出可以重投入
死亡最后结果

复盘 7 问

  1. 我为什么站在这里？
  2. 这个位置的价值来自什么？
  3. 此时谁能威胁我？
  4. 我有哪些退出/保命资源？
  5. 哪个资源为什么提前没了？
  6. 队友位置或敌方注意力何时变化？
  7. 第一个“不改就会继续出事”的错误是什么？

第一个不可逆错误

复盘不要一次写五个问题。“准星歪、技能慢、位置深、队友没跟”同时改等于什么都没改。优先找最上游、最可重复修正的那个错误。

例：“我死于 Winston 跳我”不是规则；“敌方集体突进威胁没出现时，我在没有 Sleep 的情况下仍离掩体两步以上”才是一条能在下一局执行的规则。

三条死亡因果链

把“我怎么死”改成“从哪一刻开始，我的选择越来越少”

Ana：瓶子先被迫自保

  1. 离墙太远多贪一枪
  2. 被侧面碰到，只能把生化手雷（Biotic Grenade）交给自己
  3. 敌方看到手雷没了，更敢向前
  4. 睡眠针（Sleep Dart）一空，最后被集体突进

真正根因：不是“睡眠没中”，而是更早的位置让主动资源变成了止损资源。

Tracer：回溯没了，位置却没收

  1. 第一次侧翼用 Recall 保命
  2. 队友还没接团，她仍留在深角
  3. 敌人知道她没有恢复大段血量和回位能力
  4. 原本可承担的风险变成不可承担

真正根因：资源状态变化后，没有同步降低暴露。

Winston：第一跳就把所有路都封死

  1. 没确认队友能否看见落点
  2. Jump Pack 直接落到敌方深处
  3. Barrier 被迫立刻用来生存，而不是切断支援
  4. 第二次 Jump 还没好，敌人围住撤退线

真正根因：把“进入工具”同时当成“唯一退出工具”，却没有给退出留时间。

复盘原则：最后一个失误通常最显眼，但最值得改的是“最早那个让后续选择明显变差”的错误。因为修它，后面一串错误往往一起消失。
07
COOLDOWN ECONOMY

技能不只是按钮；它决定未来几秒你敢站多深、敢不敢进、还能不能退

有位移时，你可以站得更大胆；位移一交，同一个位置可能立刻变危险。判断技能价值，要看它让谁多了选择、谁少了选择。

先说人话
技能最重要的价值，是让你“有资格”做某些动作

有位移时你敢站深一点；保命技能没了，你就该收一点。技能不是只有按出去那一刻才有价值——只要它还在，对手就必须尊重它可能造成的后果。

位移
位移 / 退出技能决定你敢不敢站得更靠前，以及出事后能不能回来
可用
控制
控制 / 否决技能让对手不敢轻易重投入进场
可用
保命
保命 / 净化已经在上一轮施压中被迫交掉
冷却中
行动余量 · 你还能承担多少风险

技能一少，你能安全站的位置也要跟着收回来

技能多 ≠ 一定要冲；但关键退出权缺失时，你必须降低暴露与承诺程度。很多阵亡说白了就是：保命手段已经没了，人却还站在刚才那个危险位置。

技能用前问目的我是制造优势，还是被迫止损？

2

技能用后问自己还能不能站这我还能继续站这里吗？

3

交换后问有没有趁机占便宜对方关键技能没了，我们有没有在它转好之前前压、转火或拿位置？

错误技能交换

你用一个技能逼出对面更长冷却时间，看起来“赚了”，但为了逼这个技能你走得过深、失去退出权，随后死亡。账面冷却时间赚，整波资源亏。

优质技能交换

你在安全位置用低成本施压逼出对手关键保命；队友马上前压，让对手在恢复前失去空间。技能差真正被换成了位置和目标进度。

更深一层：技能没按出去，也可能有价值。Ana 的 Sleep Dart 只要仍在手，就可能让 Winston 不敢不计后果地往深处跳；Tracer 的 Recall 仍在，会允许她维持更激进的注意力牵制。这叫“威胁性资源”——它通过潜在后果改变对方行为。

按钮背后的权限

同一个技能，真正价值要看它让谁能做什么、谁不敢做什么

Winston · Jump Pack

表面：跳跃和落地伤害。

更深：把 Winston 从“只能走过去”变成“可以瞬间出现在高台/后排”。它购买的是空间跨越权。Jump 用掉以后，他的退出权也进入冷却，所以落点必须考虑下一步。

Winston · Barrier Projector

表面：一个护盾。

更深：它能暂时切断敌我视线，让治疗、伤害或控制不能自由穿过。好护盾经常不是单纯“挡多少伤害”，而是把局部战斗从多人支援改成短暂的小人数战。

Tracer · Blink / Recall

表面：位移 / 回到之前的位置和生命状态。

更深：Blink 是调整角度和距离的资本；Recall 是承担风险的保险。Recall 还在时，她能把血量当可再生资源去换注意力；Recall 一交，同样的深度就需要立刻降档。

Ana · Sleep Dart / Biotic Grenade

表面：睡眠 / 治疗与禁疗。

更深：Sleep 在手本身就能否决某些进场；Grenade 既能主动制造“无法被治疗”的击杀窗口，也能被迫拿来救自己。主动用和被迫用，战略价值完全不同。

一个非常重要的区分：

软投入是可撤回、成本较低的试探，例如隔掩体打几枪；重投入是把位移、控制、爆发等同时压进去，撤回成本很高。不要在还没看到窗口时就提前重投入。

08
POSITIONING

好位置不是地图上的固定坐标，而是“你能有效做事、自己又不容易出事”的位置关系

同一个坐标，队友一起向前时可能是好侧角；队友一退，你还留原地，就可能马上变成一个人送。站位必须跟着双方的人数、技能和位置一起变化。

先说人话
站位不是背地图答案，而是看“关系”

好位置必须同时回答四件事：我在这里能做什么？敌人能怎么打我？队友能不能帮我？出事后我怎么走？其中任何一项变化，位置的好坏都可能立刻改变。

互动战术图：同一位置为什么会从好变坏

掩体（Cover）

最好不是“附近有墙”，而是一步之内能断至少一条致命视线。

有效距离（Range）

你的有效距离与敌人有效距离的关系。远离自己优势距离，就要付更多资源。

角度（Angle）

让敌人的同一块掩体不能同时解决所有威胁，但不要把自己变成孤立点。

退路（Exit）

真正好位置自带退出方案。只有进入路线、没有退出路线的“好角度”，往往只是暂时的陷阱。

四问站位法

不会地图点位也没关系：每换一个位置，问这四个问题

1. 我在这里能做什么？

打谁、奶谁、控制哪个入口？如果答案是“几乎什么都做不了”，再安全也不是好位置。

2. 谁能伤到我？

不是只数敌人，而是数枪线、控制、突进路线。两条独立角度同时看你，风险往往不是简单相加。

3. 谁能帮到我？

队友是否有视线？坦克是否能吸走注意力？如果你需要队友救，但队友根本看不到你，就是孤立。

4. 出事后怎么走？

一步断视线和三步才能到墙后，是完全不同的风险。退出路线越长，你越依赖技能和治疗。

站位的本质是“成本函数”。好位置不是永远安全，而是让你制造同样作用时付更少成本；当队友、敌人、技能状态变化，成本函数也立刻变化。
09
TIMING / TURN

时机（Timing）不是“感觉”，而是多个条件同时成熟的机会窗口

你不需要等“完美时机”，但要知道什么条件会让同一个动作从送死变成好机会。

先说人话
时机就是“现在做这件事，队友和敌人的条件合不合拍”

同一个侧翼，早 3 秒可能是送；晚 3 秒可能没意义；刚好在正面开始施压时出现，才会让敌人顾前顾后。动作对不对，不能和时间分开看。

CASE A · TOO EARLY

过早侧翼

你先出现 → 敌方没有其他施压需要处理 → 3 人一起转头 → 你被迫 Recall/撤退 → 等队友真正接战时，你的关键资源反而没了。

CASE B · SYNCHRONIZED

同步侧翼

正面已施压 → 敌人必须决定看前还是看侧 → 注意力分裂 → 你的低伤害也可能迫使辅助退位 → 正面因此获得空间。

队友已到位己方关键资源齐全敌方保命已交目标位置变差有退出路线目标即将迫使交战

行动回合：可以理解成“现在是谁的回合”。当你人数、位置、技能或目标时间占优，你更有资格主动前压；当你刚交完关键资源或队友还没到，最好的行动可能只是保持压力、拖时间、等待资源回来，而不是硬重投入。

三只时钟

判断“现在是不是我的回合”，同时看三只钟

队伍时钟

队友到位了吗？关键角色能看到同一个区域吗？你先动但队友还在走路，通常只是把自己暴露给五个人。

技能时钟

己方关键技能何时回来？敌方刚交的保命多久恢复？窗口不是永久的，很多优势只有几秒。

目标时钟

占点进度、推车检查点、加时、复活波次都会强迫人改变位置。目标时间能把“可以慢慢等”变成“现在必须露头”。

最常见的时机错误：

动作本身没错，但你把它和队友错开了。比如侧翼玩家提前出现，被迫交 Recall；两秒后正面才接触——这时最宝贵的侧面压力已经消失。同步不代表同一秒按技能，而是让多股压力在对手难以分别处理的时间段重叠。
